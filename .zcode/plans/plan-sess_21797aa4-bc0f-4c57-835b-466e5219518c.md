# AI Resume Builder Implementation Plan (OpenRouter)

## Overview
Add AI-powered features to the left editor panel (`ResumeEditor`) and a "Templates" button on the top toolbar using **OpenRouter API** (single key, multiple models). **Right preview panel remains untouched.**

---

## Phase 1: Backend - OpenRouter AI Service & Routes

### New Files
```
server/src/
├── services/openRouterService.js     # OpenRouter client + prompts
├── routes/aiResume.js                # Express routes under /api/ai/resume
```

### API Endpoints (all POST `/api/ai/resume/*`)
| Endpoint | Input | Output |
|----------|-------|--------|
| `/summary` | `{ experience[], skills[], targetRole? }` | `{ summary: string }` |
| `/experience-bullets` | `{ company, role, description, achievements[] }` | `{ bullets: string[] }` |
| `/project-description` | `{ name, techStack[], goal }` | `{ description: string }` |
| `/suggest-skills` | `{ targetRole, currentSkills[] }` | `{ skillGroups: {title, items[]}[] }` |
| `/rewrite` | `{ text, instruction }` | `{ rewritten: string }` |
| `/ats-score` | `{ resume, targetJD? }` | `{ score: number, missingKeywords: string[], suggestions: string[] }` |

### OpenRouter Config
- **Model**: `openai/gpt-4o-mini` (cheap, fast) or `anthropic/claude-3.5-haiku`
- **Env**: `OPENROUTER_API_KEY` in `server/.env`
- **Base URL**: `https://openrouter.ai/api/v1`
- **Headers**: `Authorization: Bearer $KEY`, `HTTP-Referer`, `X-Title`

### Server Registration
- Add route mount in `server/src/server.js`: `app.use('/api/ai/resume', aiResumeRoutes)`

## Phase 2: Frontend - AI Hook & Types (`client/lib/aiResume.ts`)

### Types
```typescript
interface AIResumeActions {
  generateSummary: (ctx: { experience: ResumeExperience[]; skills: string[]; targetRole?: string }) => Promise<string>;
  generateExperienceBullets: (ctx: { company: string; role: string; description: string }) => Promise<string[]>;
  generateProjectDescription: (ctx: { name: string; techStack: string[]; goal: string }) => Promise<string>;
  suggestSkills: (ctx: { targetRole: string; currentSkills: string[] }) => Promise<{ title: string; items: string[] }[]>;
  rewriteText: (text: string, instruction: string) => Promise<string>;
  getATSScore: (resume: Resume, targetJD?: string) => Promise<{ score: number; missingKeywords: string[]; suggestions: string[] }>;
}
```

### `useAIResume` Hook
- Calls `/api/ai/resume/*` via `fetch`
- Returns `{ actions, isLoading, error }`
- Shows `sonner` toasts for errors
- **Streaming**: Simple async first (can upgrade to SSE later)

## Phase 3: Option A - Per-Section AI Buttons

### New Component: `client/components/resume-builder/AISectionButtons.tsx`
Exports:
- `AIGenerateSummaryButton` — uses `generateSummary` from current resume context
- `AIExperienceBulletsButton` — modal with company/role inputs → generates 4-5 bullets
- `AIProjectDescriptionButton` — modal with tech stack/goal → generates description
- `AISuggestSkillsButton` — modal with target role input → returns skill groups
- `AIRewriteIcon` — small ✨ on textareas → popover with rewrite options (polish, shorten, quantify, action-verbs)

### Integration in `ResumeEditor` (inside `ResumeBuilder.tsx`)
Modify `EditorSection` to accept optional `aiAction` prop:
```tsx
<EditorSection title="Summary" aiAction={<AIGenerateSummaryButton resume={resume} update={update} />}>

<EditorSection title="Projects" aiAction={<AIProjectDescriptionButton update={update} />}>
<EditorSection title="Skills" aiAction={<AISuggestSkillsButton resume={resume} update={update} />}>
```

Add `AIRewriteIcon` to:
- Summary textarea
